# Define self-service data migration compatibility

Type: grilling
Status: open
Blocked by: 03, 05, 07, 10

## Question

Define how a person exports a complete JSON backup from the Lakebed app and imports it after Google sign-in on the destination: format/version compatibility, ownership reassignment, validation, duplicate/retry behavior, local and remote replacement semantics, size limits, failure recovery, unsupported-feature handling, user instructions, and proof that no data is silently lost.
