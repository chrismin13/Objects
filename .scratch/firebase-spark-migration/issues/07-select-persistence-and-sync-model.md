Type: grilling
Status: open

## Question

Choose the Firestore representation and synchronization semantics for the retained Objects behaviors: workspace document versus normalized collections or another shape, ownership boundaries, ordering, revisions, atomic changes, conflict resolution, offline writes, subscriptions, schema evolution, and limits. Decide whether the existing synchronization client remains, narrows, or is replaced by Firebase facilities.
